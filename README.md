# 🚗 Car Price Prediction Using Machine Learning

This project builds a machine learning model to **predict used car prices** based on features like brand, mileage, year, engine power, and more. It's designed to help car buyers and sellers estimate a fair market value.

---

## 📊 Dataset Overview

We use a dataset of used cars with features like:

- **Brand**: Manufacturer name (e.g., Honda, BMW)
- **Year**: Year of manufacture
- **Kilometers Driven**: Total distance driven
- **Mileage**: Fuel efficiency (kmpl)
- **Engine**: Engine size (cc)
- **Power**: Horsepower (bhp)
- **Seats**: Number of seats
- **Fuel Type**: Petrol, Diesel, etc.
- **Transmission**: Manual or Automatic
- **Location**: City of sale
- **Price**: (Target) Selling price in lakhs

Dataset link: [Kaggle Dataset](https://www.kaggle.com/datasets/vijayaadithyanvg/car-price-predictionused-cars)
